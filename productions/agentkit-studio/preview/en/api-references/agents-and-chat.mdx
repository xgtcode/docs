Harness agents use `agent_id`; runtime agents use `runtime_id`. Sessions, attachments, and memory can contain user data. Verify resource IDs before deletion. Sending messages to an agent can incur model charges.

Paths assume the default `/studio` mount. For parameters, responses, and permissions, see [BFF endpoints](/productions/agentkit-studio/preview/en/api-references/bff).
