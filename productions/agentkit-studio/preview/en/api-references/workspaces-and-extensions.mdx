Use these endpoints to import and run projects, install extensions, or manage knowledge bases and skill libraries. Starting an environment or deploying a project can incur cloud charges. Check resource IDs before deletion.

Paths assume the default `/studio` mount. For parameters, responses, and permissions, see [BFF endpoints](/productions/agentkit-studio/preview/en/api-references/bff).
