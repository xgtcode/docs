Use these endpoints to manage datasets, generate reports, run load tests, or schedule tasks. Evaluations, load tests, and scheduled runs execute real workloads and can incur charges.

Paths assume the default `/studio` mount. For parameters, responses, and permissions, see [BFF endpoints](/productions/agentkit-studio/preview/en/api-references/bff).

## Evaluation resources

| Method | Request path | Purpose |
| --- | --- | --- |

| `POST` | `/studio/api/v1/evaluation/datasets` | Create dataset |
| `GET` | `/studio/api/v1/evaluation/datasets/{dataset_id}` | Get dataset |
| `POST` | `/studio/api/v1/evaluation/datasets/update` | Update dataset |
| `POST` | `/studio/api/v1/evaluation/datasets/delete` | Delete dataset |
| `POST` | `/studio/api/v1/evaluation/datasets/generate` | Generate dataset |
| `GET` | `/studio/api/v1/evaluation/metrics` | List metrics |
| `POST` | `/studio/api/v1/evaluation/feedback/datasets` | Initialize datasets |
| `POST` | `/studio/api/v1/evaluation/feedback/update` | Save feedback |

| `GET` | `/studio/api/v1/evaluation/feedback` | List feedback |
| `GET` | `/studio/api/v1/evaluation/custom_metrics` | List custom metrics |
| `GET` | `/studio/api/v1/evaluation/custom_metrics/{custom_metric_id}` | Get custom metric |

## Scheduled tasks

| Method | Request path | Purpose |
| --- | --- | --- |
| `GET` | `/studio/api/v1/cronjobs` | List cronjobs in the supplied cloud scope |
| `POST` | `/studio/api/v1/cronjobs` | Create a cronjob definition |
| `GET` | `/studio/api/v1/cronjobs/{cronjob_id}` | Read a cronjob in the supplied cloud scope |
| `POST` | `/studio/api/v1/cronjobs/update` | Update supplied fields, including enabled; replace schedule as a whole |
| `POST` | `/studio/api/v1/cronjobs/delete` | Delete a cronjob after checking for active execution |
| `POST` | `/studio/api/v1/cronjobs/run` | Queue one manual execution of an enabled cronjob |
| `GET` | `/studio/api/v1/cronjob_runs` | List execution history for the supplied cronjob |
| `POST` | `/studio/api/v1/cronjob_runs/cancel` | Request cancellation of one execution without disabling its cronjob |
