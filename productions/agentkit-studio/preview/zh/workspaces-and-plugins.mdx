工作区用于编辑和运行项目源码；插件为智能体提供可复用的技能、知识、对话卡片和执行环境。如果只是给已有智能体补充知识或技能，不必为它创建代码项目。

## 开发或迁移项目

<Warning>
项目代码会上传到云工作区，并可能在沙箱中执行。不要上传密钥、生产配置或未经授权的源码。运行沙箱、调用模型和部署运行时可能产生费用。
</Warning>

1. 确认当前云账号、地域和项目正确，且 Studio 已配置开发沙箱。在侧栏打开**工作区**。
2. 如果要直接编辑源码，创建普通项目，可从空项目、ZIP 或 GitHub 仓库开始；私有仓库需要先授权 GitHub App。如果需要把已有应用转换为可运行的智能体项目，选择迁移项目，上传源文件并检查迁移结果。
3. 打开项目，在编辑器中检查文件，在项目调试面板输入一条测试消息。修改代码后重新加载智能体并再测一次。对于迁移项目，在迁移完成后打开输出项目继续修改，原项目保留迁移记录。
4. 在项目中运行评测，检查样本结果，再决定是否部署。项目调试成功不会自动发布服务；部署前核对目标运行时、地域及项目权限。

## 为智能体选择插件

| 插件 | 用法 |
| --- | --- |
| 技能 | 在技能库中选择「从 GitHub 导入」，检查仓库和技能内容，导入后在智能体配置中选择。例如，把团队周报的编写规则作为技能复用。 |
| 知识库 | 为产品手册准备知识库并检查文档处理状态，再把知识库添加到智能体，用手册中的真实问题验证检索结果。 |
| 对话卡片 | 预览官方卡片，或使用简易模式制作个人卡片。预览版的新对话和普通调试默认不挂载卡片。要使用审批卡片，在对话输入框的「配置 → 附加能力 → 聊天卡片」中选中该卡片，再让支持卡片的智能体发起审批。已有会话保留之前的选择。 |
| 环境 | 选择适合任务的执行环境，让智能体在沙箱中处理文件或运行工具。官方环境可安装并更新；请只挂载任务所需的数据。 |
| 产物 | 在产物列表查找或预览任务生成的文件，以便在对话结束后检查交付结果。 |

## 添加侧栏应用

对话卡片用于展示单次回复中的内容。如果需要一个可以反复打开的独立页面，从**更多 → Studio 扩展**创建或导入应用扩展。完成构建并保存后，在扩展详情中装载应用；它会出现在本人侧栏的「应用」分组中。卸载只移除侧栏入口，不等于删除扩展。
