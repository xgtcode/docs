使用这些接口导入和运行代码项目、安装扩展或维护知识库与技能库。启动开发环境或部署项目可能产生云资源费用；删除前请核对项目或资源标识。

路径以默认挂载位置 `/studio` 为例。参数、响应和权限见 [BFF 接口列表](/productions/agentkit-studio/preview/zh/api-references/bff)。

## 云工作区

| 方法 | 请求路径 | 用途 |

| `GET` | `/studio/api/v1/cloud_workspaces/projects/codex/{name}` | 读取工作区中的 Codex 配置 |

| `POST` | `/studio/api/v1/cloud_workspaces/projects/workbench/development` | 准备项目的开发会话 |
| `POST` | `/studio/api/v1/cloud_workspaces/projects/workbench/runtime` | 查询、启动或重启项目运行时 |
