下面创建一个只负责提取会议待办的通用智能体。不需要上传源码、接入企业数据或为它单独部署运行时。

## 准备运行时和模型

用有权创建智能体的账号登录 Studio。通用智能体通过共享的 Harness 运行时执行。首次配置时，请有权限的用户到设置中的 **Harness Agent 运行时**部署或关联运行时，确认状态就绪，并准备有权调用的模型和模型凭据。只看到 Studio 首页，并不代表模型已可调用。

## 验证第一次回答

1. 在首页选择**创建智能体**，然后选择**从空白创建**，进入通用智能体的单智能体配置页。也可以直接描述需求，让 Studio 生成初始配置，再自行检查。
2. 将名称设为「会议待办助手」，选择可用模型，填写系统提示词：`从会议记录中提取待办事项，每项列出负责人和截止时间。未提供的信息写“未指定”，不要推测。` 本例不需要工具或知识库。
3. 在右侧调试对话中输入：`周四前由林悦发送报价单。另需预约会议室，未指定负责人。` 检查报价单的负责人和截止时间，以及预约会议室的缺失信息。回答补写了负责人时，调整提示词，用同一段记录再测一次。
4. 保存配置。如果出现生成默认评测集的提示，可以选择自动生成或暂不生成。从智能体列表重新打开已保存的智能体，发起正式对话。仅调试而不保存，关闭页面后不会保留配置修改。

## 什么时候增加能力

| 需要解决的问题 | 配置方式 |
| --- | --- |
| 回答依赖内部资料 | 在插件中准备知识库，确认文档可检索后，再在智能体配置中选择该知识库。 |
| 需要调用外部服务 | 在配置中添加所需的工具或 MCP 服务，再用能触发该工具的问题进行调试，查看实际调用结果。 |
| 需要跨会话记住用户偏好 | 在运行时设置中选择「配置当前运行时」，绑定 Viking 记忆库并保存，再在单智能体的「记忆」中启用「为使用者画像」。例如，添加一个字段，只记录用户明确指定的回答语言。保存后在正式对话中表达偏好；画像异步生成。记忆库用于记录偏好，会话存储用于保留对话，两者可分别配置。 |
| 需要多个智能体分工 | 选择多智能体模式，在工作流画布上配置节点并连接执行顺序。例如先提取待办，再让复核节点检查遗漏；需要同时执行的分支用并行节点表示。 |

保存通用智能体配置不会创建新的云运行时。如果需要在自己的代码项目中安装依赖、修改文件或单独部署服务，请使用[工作区](/productions/agentkit-studio/preview/zh/workspaces-and-plugins)。

## 导出源码

要把配置交给开发团队，在已保存智能体的详情中选择**导出代码**。导出的 VeADK 项目保留指令、工具及资源引用，但不包含云凭据或 Studio 对话历史。资源引用仍指向原来的云项目；在其他环境运行前，请配置有权访问这些资源的凭据，或替换资源引用。

## 从代码包部署 Runtime 智能体

如果已有可运行的服务，可以跳过通用智能体配置，直接把代码包部署到独立运行时。这是 11 月 19 日预览版的功能，需要 Studio 管理员权限。

<Warning>
部署会将代码包上传到工作台配置的 TOS 桶，并在所选云项目和地域创建可能产生费用的运行时。请先移除包中的凭据，确认桶允许来自 Studio 网页来源的跨域 PUT 请求。
</Warning>

1. 在**智能体 → 新建 → Runtime 智能体**填写名称并选择代码包。
2. 填写包内可执行的启动脚本和服务端口，默认分别为 `run.sh` 和 `8000`。服务必须监听 `0.0.0.0` 及所填端口；界面上的端口设置不会修改程序的监听地址。
3. 提交后查看部署状态。返回 Runtime ID 表示请求已受理，关闭弹窗不会停止部署。部署就绪后，如果服务实现了 ADK 对话协议，可以在详情页选择**开始对话**验证；普通 HTTP 服务部署成功不代表可以在 Studio 中对话。
