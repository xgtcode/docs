Install VeADK to create and run agents in Python. This page covers the released `1.1.26` version; production projects should pin this version or another internally verified version.

## Prerequisites

- Python 3.10 through 3.13, with pip available in that environment
- An available model and API key to run an agent; installing the package does not require model credentials. See the [Quickstart](/productions/veadk/archives/1.1.26/en/get-started/quickstart) for Volcengine and BytePlus configuration

## Install 1.1.26

Create a virtual environment in your project directory to isolate its dependencies:

```bash lines
python -m venv .venv
```

Activate the environment:

<Tabs>
  <Tab title="macOS / Linux">
    ```bash lines
    source .venv/bin/activate
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell lines
    .venv\Scripts\Activate.ps1
    ```
  </Tab>
</Tabs>

Install 1.1.26 from [PyPI](https://pypi.org/project/veadk-python/) and check the installation:

```bash lines
python -m pip install "veadk-python==1.1.26"
python -c "from importlib.metadata import version; print(version('veadk-python'))"
```

The second command should print `1.1.26`. The Python requirements and extras on this page were checked against release 1.1.26.

## Optional dependency groups

Install extras for the integrations you need. For example, install `extensions` for Feishu, Cozeloop, or LlamaIndex:

```bash lines
python -m pip install "veadk-python[extensions]==1.1.26"
```

If you pin the base package, use the same version for extras, for example `veadk-python[extensions]==1.1.26`.

| Extra | Included capabilities or dependencies |
| --- | --- |
| `github-cicd` | PyNaCl to encrypt GitHub Actions Secrets for Studio continuous delivery |
| `extensions` | Feishu channel and OpenAPI SDKs, Cozeloop, LlamaIndex with OpenAI-compatible model and embedding adapters, and Redis / OpenSearch / Milvus retrieval adapters and clients |
| `codex` | OpenAI Codex SDK, Codex CLI binary, FastAPI, and Uvicorn for the Codex runtime |
| `database` | Redis, PyMySQL, Volcengine SDK, and Mem0 storage dependencies |
| `eval` | DeepEval, Google ADK evaluation dependencies, and the Prometheus metrics client |
| `a2ui` | A2UI Agent SDK for generating A2UI interface content |
| `harness` | Headroom integration dependency |
| `harness-sidecar` | AgentKit Python SDK for the Harness Sidecar managed runtime |
| `sandbox` | Anthropic SDK, python-dotenv, and httpx SOCKS proxy support for the self-hosted sandbox example |
| `dev` | pre-commit, pytest, pytest-asyncio, pytest-cov, and pytest-xdist for development and testing |
| `pdf`, `speech`, `cli` | Empty extras retained for existing installation commands; PDF rendering dependencies have been included in the base package since 1.0.5 |

## Install 1.1.26 from source

Install Git and [uv](https://docs.astral.sh/uv/), then clone the public repository at the `1.1.26` tag. Create an isolated environment inside the repository and install VeADK in editable mode:

```bash lines
git clone --branch 1.1.26 --depth 1 https://github.com/volcengine/veadk-python.git
cd veadk-python
```

```bash lines
uv venv --python 3.12
uv pip install -e .
```

To include an extra, replace the installation command with `uv pip install -e ".[extensions]"`

Activate the repository's `.venv` using the instructions above, then run the version check command. With an editable installation, changes to the repository's Python source apply to that environment

To run your first agent, see the [Quickstart](/productions/veadk/archives/1.1.26/en/get-started/quickstart).
