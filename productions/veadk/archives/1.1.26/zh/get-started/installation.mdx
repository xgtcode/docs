安装 VeADK 后，可以使用 Python 创建和运行智能体。本页对应 `1.1.26` 已发布版本；生产项目建议固定该版本或内部验证过的版本。

## 前置条件

- Python 3.10 至 3.13，以及对应环境中的 pip
- 调用模型时需要可用的模型和 API Key；安装软件包本身不需要模型凭证。火山引擎和 BytePlus 的配置见[快速开始](/productions/veadk/archives/1.1.26/zh/get-started/quickstart)

## 安装 1.1.26

在项目目录中创建虚拟环境，避免与其他项目的依赖冲突：

```bash lines
python -m venv .venv
```

激活该环境：

<Tabs>
  <Tab title="macOS / Linux">
    ```bash lines
    source .venv/bin/activate
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell lines
    .venv\Scripts\Activate.ps1
    ```
  </Tab>
</Tabs>

从 [PyPI](https://pypi.org/project/veadk-python/) 安装 1.1.26，并检查安装结果：

```bash lines
python -m pip install "veadk-python==1.1.26"
python -c "from importlib.metadata import version; print(version('veadk-python'))"
```

第二条命令应输出 `1.1.26`。本页的 Python 版本要求和可选依赖组按已发布的 1.1.26 核对。

## 可选依赖组

根据需要安装可选依赖组。例如，接入飞书、Cozeloop 或 LlamaIndex 时安装 `extensions`：

```bash lines
python -m pip install "veadk-python[extensions]==1.1.26"
```

固定主包版本时，可选依赖组也应使用相同版本，例如 `veadk-python[extensions]==1.1.26`。

| 依赖组 | 包含的能力或依赖 |
| --- | --- |
| `github-cicd` | PyNaCl，用于 Studio 持续交付时加密 GitHub Actions Secret |
| `extensions` | 飞书渠道 SDK、飞书 OpenAPI SDK、Cozeloop、LlamaIndex 及其 OpenAI 兼容模型与嵌入适配、Redis / OpenSearch / Milvus 检索适配与客户端 |
| `codex` | OpenAI Codex SDK、Codex CLI 二进制文件、FastAPI 和 Uvicorn，用于 Codex 运行时 |
| `database` | Redis、PyMySQL、火山引擎 SDK 和 Mem0 存储依赖 |
| `eval` | DeepEval、Google ADK 评测依赖和 Prometheus 指标客户端 |
| `a2ui` | A2UI Agent SDK，用于生成 A2UI 界面内容 |
| `harness` | Headroom 集成依赖 |
| `harness-sidecar` | Harness Sidecar 受控运行时所需的 AgentKit Python SDK |
| `sandbox` | 自建沙箱示例所需的 Anthropic SDK、python-dotenv 和 httpx SOCKS 代理支持 |
| `dev` | pre-commit、pytest、pytest-asyncio、pytest-cov 和 pytest-xdist，用于开发与测试 |
| `pdf`、`speech`、`cli` | 兼容已有安装命令的空依赖组，不增加额外依赖；PDF 页面渲染依赖自 1.0.5 起随主包安装 |

## 从源码安装 1.1.26

需要 Git 和 [uv](https://docs.astral.sh/uv/)。克隆公开仓库的 `1.1.26` tag，在仓库目录中创建独立环境并以可编辑模式安装：

```bash lines
git clone --branch 1.1.26 --depth 1 https://github.com/volcengine/veadk-python.git
cd veadk-python
```

```bash lines
uv venv --python 3.12
uv pip install -e .
```

需要可选依赖组时，将安装命令改为 `uv pip install -e ".[extensions]"`

使用前激活仓库中的 `.venv`，激活方式与上文相同，再执行版本检查命令。可编辑安装后，对仓库中 Python 源码的修改会作用于该环境

运行第一个智能体见[快速开始](/productions/veadk/archives/1.1.26/zh/get-started/quickstart)。
