To debug a local Python agent, use [VeADK Web](/productions/veadk/preview/en/components/frontend/veadk-web). Send a test message in the browser, then inspect its session, tool calls, and execution events.

To import projects, develop agents, or run evaluations in a cloud workbench, see [AgentKit Studio](/productions/agentkit-studio/preview/en).
